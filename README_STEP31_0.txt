SAWOL OFFICE STEP31.0 — 대표 관제실 최종 정리

목표
대표가 직원 내부 진행상황을 일일이 따라다니지 않고,
'지금 회사가 정상인지 / 내가 판단할 게 있는지 / 결과가 얼마나 나왔는지'를
첫 화면에서 바로 알 수 있게 대표실 대시보드를 정리합니다.

이번 단계
- 대표실 상단을 CEO CONTROL ROOM 형태로 재구성
- 대표 판단 필요 여부를 가장 먼저 표시
- 윤서진 비서실장 브리핑을 대표 판단 큐와 결합
- 진행 프로젝트 / 진행 업무 / 활동 직원 / 오늘 완료를 한 번에 표시
- 승인 / 대표 판단 / 오류·복구를 우측 판단 패널에 분리
- 라이브 오피스 / 비서실 / 조직·직원 / 프로젝트 관제로 빠르게 이동
- 기존 상세 운영 정보(AUTO 현황, 협업, 최근 업무)는 아래에 그대로 유지
