SAWOL OFFICE STEP26.1 — PIXEL LIVE OFFICE V2

목표
- 90명 규모 직원이 '업무가 없을 때도 자기 자리에 있는' 회사형 픽셀 오피스
- 대표 지시 → 비서 분석 → 직원 A → 직원 B → 직원 C → 비서 취합 → 대표 보고 흐름 시각화
- 기존 DB/업무/승인/Discord/AI 실행 로직을 건드리지 않는 읽기 중심 UI 레이어

핵심 디자인
- 화이트 / 차콜 / 스카이블루 / 블루그레이 기업형 팔레트
- 핑크 계열 사용 안 함
- 과한 게임 UI가 아니라 운영툴 + 픽셀 회사 시뮬레이션의 중간 톤
- 모든 직원은 idle 상태에서도 자리와 책상에 표시
- WORKING / REVIEW / APPROVAL / ERROR / WAITING DATA 상태를 모니터/상태 점으로 시각화

90명 대응
- 전체 회사 → 부서 → 직원의 3단계 정보 밀도
- 부서별 room card 안에 전 직원을 실제로 배치
- 내부 오피스 캔버스를 스크롤하고 70~120% 줌 가능
- 활동 직원만 보기 토글 제공
- 이름/상세는 직원 클릭 시 우측 패널에서 확인

협업 시각화
- 진행 workflow 선택 시 참여 직원 전체가 오피스에서 하이라이트
- 하단 업무 이동 레일에:
  대표 지시 → 비서 분석 → 담당 직원들 → 비서 취합 → 대표 보고
- 최근 task_handoffs를 우측에 별도 표시

안전 원칙
- SQL 없음
- 환경변수 없음
- npm 추가 없음
- 기존 AUTO/MANUAL 로직 수정 없음
- 기존 승인/결과/Discord 수정 없음
- app/office/page.tsx만 교체하고 새로운 클라이언트 UI 컴포넌트 1개 추가

변경 파일
- app/office/page.tsx
- components/sawol/pixel-live-office.tsx
- README_STEP26_1_PIXEL_LIVE_OFFICE.txt

테스트 체크
1. /office 정상 진입
2. 전체 직원 수가 실제 활성 직원 명부 수와 일치
3. 업무 없는 직원도 부서 방에 표시
4. 진행 workflow 클릭 시 해당 직원들이 강조
5. 직원 클릭 시 현재 상태/업무/전문 분야 표시
6. 최근 인수인계 A → B 표시
7. 줌 +/- 정상 작동
8. 활동 직원만 토글 정상 작동
9. 모바일에서 페이지가 깨지지 않고 내부 오피스만 스크롤
10. 기존 대표실/업무지시/승인/결과 화면에 영향 없음
