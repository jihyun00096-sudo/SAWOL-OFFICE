SAWOL OFFICE STEP26.2 — Focus Real Office

기준
- STEP26.1 PIXEL LIVE OFFICE V2 적용 상태 위에 덮는 패치
- 기존 DB / AUTO / MANUAL / 승인 / 결과 / Discord / AI 로직은 변경하지 않음
- 화면 표현 레이어만 수정

이번 변경
1. 집중모드
- 라이브 오피스를 브라우저 내부 전체 화면처럼 크게 표시
- 기존 SAWOL 좌측 메뉴/상단 영역을 오피스가 덮어 실제 상황판처럼 사용 가능
- 나가기 버튼으로 즉시 복귀

2. 큰 가상 오피스 캔버스
- 90명을 작은 카드 안에 억지로 축소하지 않음
- 55%~125% 줌 지원
- 빈 공간을 마우스로 드래그해 이동
- 전체 → 부서 → 직원 방식으로 확인

3. 진짜 오피스형 공간 구성
- MAIN ENTRANCE / 로비
- 대표실
- 윤서진 비서실·중앙 관제
- 결과 데스크
- MAIN CORRIDOR
- 부서별 사무실 ROOM
- 각 층/구역 사이 실제 복도
- 회의실
- 업무 전달 라운지
- 휴게/탕비존
- 화분, 벤치, 출입문, 유리벽 느낌의 공간 디테일

4. 직원 표현
- 업무가 없어도 각 부서 자기 자리에 표시
- WORKING / REVIEW / APPROVAL / WAITING / ERROR 상태 유지
- 직원 클릭 시 우측 슬라이드 상세 패널
- 선택 workflow 직원 하이라이트 유지

5. 우측 고정 패널 제거
- 오피스 공간을 좁히던 상시 우측 패널 제거
- 업무 / 전달 / 승인 버튼만 플로팅
- 클릭할 때만 오른쪽 슬라이드 패널 오픈

6. 업무 전달
- 실제 workflow 데이터 사용
- 대표 지시 → 비서실 분석 → 담당 직원들 → 비서 취합 → 대표 보고
- 업무 전달 라운지에서 흐름 확인
