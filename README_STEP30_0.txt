SAWOL OFFICE STEP30.0 — 90인 조직 · 직원 운영체계

목표
- 90명의 AI 직원을 단순 명부가 아니라 실제 회사 조직처럼 운영·관찰
- 라이브 오피스 / 비서실 / 업무 시스템의 같은 데이터를 한 조직 관제 화면에서 사용
- 나중에 Claude/멀티모델로 바뀌어도 유지되는 조직 운영 레이어 구축

이번 단계
1. /employees 를 조직 관제 허브로 확장
- 전체 직원 수
- 실제 운영 부서 수
- 현재 업무 중 인원
- 대기 가능 인원
- 보류·오류·자료대기 등 확인 필요 인원
- 활성 업무 3건 이상 과부하 직원

2. 부서별 조직 현황
- 부서 인원
- 업무 중 인원
- 현재 활성 업무 수
- 문제/확인 필요 인원
- 가동률
- 부서 대표 전문분야
- 부서 카드를 클릭하면 해당 부서 직원 명부로 바로 필터

3. 직원 운영 명부
- 이름 / 직원코드 / 직책
- 소속 부서 / 전문분야
- 실제 employee status
- 현재 활성 업무 수
- 최근 workflow 인수인계 IN → OUT 횟수
- 최근 조회 범위의 완료 업무 수
- 과부하 / 확인 필요 표시
- 이름·직원코드·직책·전문분야 검색
- 부서 / 상태 필터
- 클릭하면 기존 직원 상세 페이지로 이동

4. 협업 흐름
- task_handoffs 실제 데이터를 사용해 최근 직원→직원 인수인계 표시
- 현재 업무량 상위 직원 별도 표시
- 비서실 자동 배정/활성 배정 건수 표시

5. 기존 시스템 보호
- DB 스키마 변경 없음
- SQL 없음
- 환경변수 없음
- npm 추가 없음
- AUTO/MANUAL 실행 로직 변경 없음
- workflow 생성/실행 로직 변경 없음
- Discord 변경 없음
- Artifact Worker 변경 없음
- Live Office 변경 없음
- 비서실 실행 로직 변경 없음
