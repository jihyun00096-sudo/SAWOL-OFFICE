SAWOL OFFICE STEP26.0 — LIVE OFFICE v1

목표
대표가 실제 회사처럼 AI 직원들이 일하고, 업무가 다음 직원에게 전달되고,
비서가 최종 결과를 취합해서 대표실로 가져오는 전체 흐름을 한 화면에서 확인합니다.

이번 버전의 원칙
- 기존 AUTO/MANUAL/업무/승인/결과/Discord 실행 로직을 변경하지 않음
- 기존 DB를 읽기만 하는 시각화 레이어
- 따라서 기존 기능에 대한 영향 최소화

추가 기능
1. 새 메뉴: 라이브 오피스 (/office)
2. 큰 오피스 보드
   - 대표실
   - 윤서진 비서실
   - 결과 데스크
   - 실제 활동 중인 부서별 공간
3. 직원 캐릭터
   - 이름
   - 현재 맡은 업무
   - 작업 중이면 LIVE pulse
   - 대기/오류 상태 표시
4. 여러 업무 동시 표시
   - 현재 진행 중인 workflow 최대 8개
   - 각 workflow별 업무 전달 라인
5. 실제 협업 흐름
   직원 A → 직원 B → 직원 C → 윤서진 비서실 → 대표
6. 최근 task_handoffs를 실제 인수인계 기록으로 표시
7. 대표 승인 대기 업무는 '비서 → 대표 보고' 영역에 표시
8. 10초 자동 새로고침
9. 모바일에서는 오피스 구역/업무 흐름이 카드형으로 자연스럽게 축약

변경 파일
- app/office/page.tsx (신규)
- components/sawol/live-office-refresh.tsx (신규)
- components/sawol/office-shell.tsx
- components/sawol/mobile-nav.tsx

SQL 없음
환경변수 없음
npm 변경 없음
기존 AI Provider 변경 없음

테스트
1. 배포 후 왼쪽 메뉴의 '라이브 오피스' 클릭
2. AUTO 협업 업무 1개 실행
3. 해당 부서 직원 캐릭터가 표시되는지 확인
4. 업무 전달 라인에서 STEP별 직원 순서가 보이는지 확인
5. 단계가 완료될 때 다음 직원으로 흐름이 넘어가는지 확인
6. 최종 승인 대기 시 윤서진 비서실 → 대표 보고 상태가 보이는지 확인

이후 STEP26.1 후보
- 직원 캐릭터 디자인 고도화
- 자리/회의실/부서 공간 배치 커스터마이징
- 업무 카드가 실제 공간 사이를 이동하는 애니메이션
- 비서가 완료 산출물을 '서류 더미'처럼 취합하는 시각화
- 프로젝트별 색상/업무별 동시 흐름 필터
