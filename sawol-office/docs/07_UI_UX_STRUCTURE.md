# SAWOL OFFICE — UI / UX STRUCTURE

## 1. STEP 7의 목적
SAWOL OFFICE의 웹사이트가 단순한 대시보드가 아니라 실제 개인 AI 회사를 운영하는 중앙 통제실처럼 작동하도록 화면 구조를 설계한다.

대표는 사이트 안에서 다음 행동을 할 수 있어야 한다.
- 새로운 업무 지시
- 프로젝트 생성 및 확인
- 직원 상태 확인
- 업무 진행상황 확인
- 결과물 검토
- 대표 승인
- 수정 지시
- 과거 프로젝트 검색
- 대표 기억 확인
- 오류 및 위험 확인
- 외부 연동 상태 확인

## 2. 전체 사이트 구조
초기 메뉴는 다음과 같이 구성한다.
1. 대표실
2. 업무지시
3. 프로젝트
4. 업무관리
5. 직원
6. 승인함
7. 결과함
8. 기억센터
9. 연구소
10. 시스템
11. 설정

초기 v0.1에서는 모든 기능을 완성하지 않고 핵심 화면부터 구현한다.

## 3. 공통 레이아웃
- 왼쪽: 사이드 메뉴
- 상단: 현재 프로젝트 / 검색 / 알림 / 대표 프로필
- 중앙: 현재 메뉴의 주요 화면
- 오른쪽 선택 영역: 업무 상세 또는 AI 비서 패널

## 4. 왼쪽 사이드바
상단에는 SAWOL OFFICE, 대표 상태, 오늘 날짜, 현재 활성 프로젝트 수를 표시한다.
주요 메뉴는 대표실, 업무지시, 프로젝트, 업무관리, 직원, 승인함, 결과함, 기억센터, R&D 연구소이며 하단에는 시스템, 연동상태, 설정을 둔다.

## 5. 대표실
대표실은 SAWOL OFFICE의 메인 화면이다. 사이트에 접속하면 가장 먼저 보이며 대표가 10초 안에 현재 회사 상황을 파악할 수 있도록 한다.

상단 요약:
- 진행 중 프로젝트
- 진행 중 업무
- 대표 승인 대기
- 자료 대기
- 오류 발생
- 오늘 완료

## 6. 비서실 브리핑
대표실 상단에 비서실장 윤서진의 브리핑을 보여준다.
예: 현재 4개 프로젝트가 진행 중이며, 타로 서비스 프로젝트는 UI 기획까지 완료되어 대표 승인 1건이 대기 중이고, Discord 연동 테스트 오류가 1건 발생했다는 식으로 핵심만 보고한다.

버튼:
- 전체 브리핑 보기
- 승인 업무 보기

## 7. 오늘 대표가 확인할 일
대표가 직접 판단해야 하는 항목만 보여준다.
각 카드에는 담당자, 상태, 검수결과, 위험, 비용을 표시하고 결과 보기 / 승인 / 수정 요청 / 보류를 제공한다.

## 8. 진행 중 프로젝트
프로젝트를 카드 형태로 표시한다.
표시 항목:
- 프로젝트명
- 상태
- 진행률
- 담당 PM
- 현재 Task
- 다음 단계
- 대표 승인 건수

## 9. 현재 업무 현황
상태별 Task 수를 표시한다.
- 진행 중
- 검수 중
- 승인 대기
- 자료 대기
- 오류

## 10. 최근 완료 업무
최근 완료한 업무를 보여주며 클릭 시 결과함으로 이동한다.

## 11. 업무지시 화면
대표가 가장 자주 사용하는 핵심 화면이다.
대표는 자연어로 지시할 수 있다.

입력 요소:
- 큰 자연어 입력창
- 첨부파일
- 이미지
- 문서
- 링크

## 12. 업무지시 옵션
기본적으로 AI가 자동 판단하지만 대표가 직접 지정할 수도 있다.

업무 유형:
- 자동 분류
- 리서치
- 기획
- 제작
- 수정
- 분석
- 운영
- 연구
- 프로젝트

우선순위:
- 자동
- 긴급
- 높음
- 보통
- 낮음

담당 부서:
- 자동 배정 또는 직접 선택

원하는 결과물:
- 자동
- 문서
- 이미지
- 웹사이트
- 코드
- 엑셀
- 리서치
- 기획안
- 기타

## 13. 업무 보내기 전 AI 분석
대표가 업무지시 버튼을 누르면 즉시 실행하지 않고 비서실이 먼저 분석한다.
분석 결과에는 프로젝트 여부, 예상 참여부서, 예상 Task, 승인 필요 여부를 표시한다.

대표 선택:
- 이대로 시작
- 업무 수정
- 취소

초기 버전은 대표 확인 후 시작하는 반자동 구조로 운영한다.

## 14. 프로젝트 화면
모든 프로젝트를 카드 또는 목록으로 관리한다.
필터:
- 전체
- 진행 중
- 기획 중
- 검수 중
- 승인 대기
- 보류
- 완료
- 폐기

## 15. 프로젝트 상세 화면
상단에는 프로젝트명, 상태, 진행률, 우선순위, 시작일, PM, 참여부서를 표시한다.
탭:
- 개요
- 업무
- 결과물
- 결정사항
- 기억
- 파일
- 활동기록

v0.1에서는 개요 / 업무 / 결과물 / 승인 기능을 우선 구현한다.

## 16. 프로젝트 개요
- 프로젝트 목적
- 최초 대표 지시
- 현재 상태
- 현재 진행단계
- 주요 결과
- 대표 확인사항
- 주요 위험
- 비용 발생 여부

## 17. 프로젝트 업무
Task를 단계별로 보여준다.
예: 조사 완료 → 기획 완료 → UI 진행 중 → DB 대기 → 개발 대기 → 검수 대기 → 대표 승인 대기.

## 18. 프로젝트 업무 시각화
초기에는 칸반 보드를 추천한다.
컬럼:
- 업무 대기
- 진행 중
- 검수 중
- 대표 승인 대기
- 완료

## 19. 업무관리
프로젝트와 관계없이 모든 Task를 확인한다.
검색/필터:
- Task명
- 담당 직원
- 프로젝트
- 부서
- 상태
보기 방식:
- 목록
- 칸반
- 직원별
- 프로젝트별

## 20. 직원 화면
전체 직원 수, 현재 업무 중, 대기 중, 승인 대기 등을 표시하고 부서별로 볼 수 있다.

## 21. 직원 카드
직원 카드에는 이름, 직책, 직원 코드, 현재 상태, 현재 프로젝트, 현재 업무, 전문성을 표시한다.
버튼:
- 직원 상세
- 업무 지시

## 22. 직원 상세 화면
- 기본정보
- 전문성
- 가능/금지 업무
- 사용 도구
- 현재 Task
- 현재 프로젝트
- 최근 완료 업무
- 최근 평가
- 대표 피드백

## 23. 직원에게 직접 업무지시
대표는 특정 직원에게 바로 업무를 줄 수 있다.
전문범위를 벗어나면 비서실이 더 적합한 직원을 추천한다.

## 24. 승인함
대표가 반드시 확인해야 하는 결과만 모은다.
분류:
- 전체
- 결과물 승인
- 비용 승인
- 배포 승인
- 외부 발송 승인
- 데이터 변경 승인
- 고위험 승인

## 25. 승인 카드
프로젝트, 요청 내용, 담당, 검수결과, 주의사항, 비용을 표시한다.
액션:
- 결과 보기
- 승인
- 수정 요청
- 보류
- 폐기

## 26. 수정 요청
입력:
- 수정할 부분
- 유지할 부분
- 절대 변경하지 않을 부분
- 추가 요청

새 Task 또는 기존 Task 수정본으로 등록한다.

## 27. 결과함
유형:
- 문서
- 이미지
- 코드
- 리서치
- 엑셀
- 데이터
- 프롬프트
- 사이트
- 기타

## 28. 결과 카드
- 제목
- 유형
- 담당
- 검수
- 프로젝트
- 버전
버튼:
- 열기
- 재사용
- 프로젝트로 이동

## 29. 결과 비교
동일 결과물의 여러 버전을 비교할 수 있도록 향후 확장한다.

## 30. 기억센터
기억 종류:
- 대표 선호
- 프로젝트 기억
- 결정사항
- 전문지식
- 실패사례
- 프롬프트
- 회사 규칙

## 31. 대표 기억 화면
중요도와 함께 대표의 선호/비선호를 표시한다.

## 32. 기억 검색
향후 자연어 검색을 지원한다.
예:
- 내가 이미지 만들 때 싫어했던 거 뭐였지?
- 전에 타로 서비스 만들면서 결정한 게 뭐야?
- 사이트 제작할 때 자주 생겼던 오류 찾아줘.

## 33. 연구소
정식 프로젝트로 바로 만들지 않을 아이디어를 자유롭게 넣는 공간이다.
평가:
- 실용성
- 난이도
- 예상비용
- 필요 기술
- 재미
- 활용 가능성
- 추천 여부

선택:
- 정식 프로젝트로 승격
- 조금 더 조사
- 보관
- 폐기

## 34. 시스템 화면
데이터베이스 및 외부 서비스 상태를 확인한다.
대상:
- Supabase
- Notion
- Discord
- GitHub
- Google Drive
- Gmail
- Calendar
상태:
- 연결됨
- 미연결
- 오류

## 35. 연동 화면
각 외부 서비스별 목적과 상태를 보여주고 연결 설정으로 이동한다.
실제 토큰은 화면에 노출하지 않는다.

## 36. 시스템 오류 화면
오류 발생시간, 원인, 영향, 재시도 기능을 제공한다.

## 37. 비용 관리
향후 AI API 사용 시 오늘/이번 달/프로젝트별/모델별 비용과 예상 추가비용을 표시한다.

## 38. 검색
상단 통합검색 대상:
- 프로젝트
- Task
- 직원
- 결과물
- 기억
- 결정사항
- 전문자료

## 39. 알림센터
- 대표 승인 요청
- Task 완료
- 프로젝트 완료
- 자료 필요
- 오류
- 위험 발견
- 비용 승인 요청

## 40. 우측 AI 비서 패널
사이트 어디에서든 윤서진 비서실장에게 질문할 수 있다.
결론을 먼저 말하고 필요할 때 상세 내용을 제공한다.

## 41. 비서 패널 응답 원칙
병목, 승인 대기, 오류 등 대표가 바로 판단해야 하는 핵심부터 전달한다.

## 42. 모바일 대응
모바일 필수 기능:
- 현재상황 확인
- 업무지시
- 결과 확인
- 승인
- 수정 요청
- 알림 확인
복잡한 개발관리나 DB 설정은 PC 중심.

## 48. 디자인 방향
일반 기업용 ERP처럼 지나치게 딱딱하지 않게 구성한다.
- 개인 사무실 느낌
- 고급스럽지만 과하지 않음
- 정보 명확
- 직원 캐릭터성
- 실제 업무 방해 최소화
- 장시간 사용 피로 최소화

## 49. 대표 사용자 경험 핵심
대표가 한 문장으로 원하는 일을 지시한다.
→ 비서실이 필요한 직원과 업무를 정리한다.
→ 직원들이 결과를 만든다.
→ 대표는 중요한 것만 확인하고 결정한다.
→ 결과와 경험은 자동으로 회사에 쌓인다.
