# SAWOL OFFICE — PRODUCT COMPLETION ROADMAP

기준일: STEP26.1 PIXEL LIVE OFFICE V2 이후

## 고정 원칙

- 기존 MANUAL 기능은 유지하고 AUTO 기능을 병행한다.
- 대표는 업무만 지시하고, AUTO에서는 비서실이 분석·배정·협업·취합 후 대표에게 승인/반려만 요청한다.
- 기존 프로젝트/업무/승인/결과/실행기록/기억센터/Discord 기능을 파괴하지 않는다.
- AI Provider(Gemini/Claude 등)와 회사 운영 구조를 분리한다.
- 지금은 전체 제품 기능을 먼저 완성하고, 모델별 프롬프트/리서치 품질/이미지 품질의 미세 튜닝은 마지막에 통합 진행한다.
- 파일 하나나 모델 한 종류 때문에 전체 개발이 장기간 멈추지 않도록 기능 단위 완료 기준을 둔다.
- 디자인은 화이트/차콜/스카이블루/블루그레이 기반의 기업형 UI를 유지한다.

## STEP 26 — LIVE OFFICE / 회사 시각화

### 26.1 완료 목표
- 90명 전체 직원 좌석 표시
- idle 직원도 자기 자리에 존재
- 부서별 오피스 구역
- 직원 상태 표시
- workflow 선택 시 참여 직원 강조
- 대표 → 비서 → 직원들 → 비서 → 대표 흐름 표시
- 실제 task_handoffs 표시
- 전체/부서/개인 3단계 정보 밀도
- 줌 및 활동 직원 필터

### 26.2 후속 디테일
- 업무 전달 문서/파일 아이콘의 가벼운 이동 애니메이션
- 현재 작업 중 직원의 키보드/모니터 상태 애니메이션
- 회의/협업 시 회의존 표현
- 부서 클릭 확대/포커스
- 대표 승인 대기 시 비서실 → 대표실 보고 연출
- 오류 발생 직원/업무 위치 바로가기
- 여러 workflow 동시 진행 시 색상 충돌 없는 하이라이트 규칙

## STEP 27 — 범용 산출물 시스템 완성

- XLSX/PDF 현재 구조 유지
- DOCX 실제 생성
- PPTX 실제 생성
- CSV/JSON/Markdown/TXT 생성
- ZIP/코드 파일 결과 지원
- 이미지 산출물과 문서 산출물의 동일 artifact 인터페이스
- 한 업무에서 여러 파일 동시 결과 제출
- 결과함에서 파일 종류/크기/생성자/관련 업무 표시
- HWP는 HWPX 또는 변환 전략을 별도 확정 후 지원

완료 기준: AI Provider가 무엇이든 구조화된 결과를 실제 파일 Worker가 생성하고 결과함까지 전달할 수 있음.

## STEP 28 — 프로젝트/업무 운영 완성

- 프로젝트와 하위 업무 관계 정리
- 하위 업무 의존성/선후행 관계
- AUTO/MANUAL 혼합 프로젝트
- 프로젝트 진행률
- 업무별 담당/협업 직원
- 재작업 이력
- 파일/결과 연결
- 프로젝트 완료/보관/삭제
- 실행 실패/보류/자료대기 상태 일관화

## STEP 29 — 윤서진 비서실 완성

- 대표 지시 분석
- 업무 복잡도 판단
- 단독/협업 판단
- 필요한 산출물 종류 판단
- 부서/직원 배정
- workflow 생성
- 직원 간 인수인계 관리
- 최종 결과 취합
- 대표 보고용 요약 생성
- 오류/자료부족/대표 판단 필요 상황만 대표에게 에스컬레이션

완료 기준: 대표가 직원 이름이나 workflow를 직접 지정하지 않아도 비서실이 업무를 끝까지 운영할 수 있음.

## STEP 31 — 대표실 / 운영 대시보드 완성

## STEP 32 — Discord 운영 완성

- 대표 업무 지시
- 업무 접수

- 숫자/날짜/고유명사 검증
- 문서 내용 품질
- Excel 구조/서식 품질
- PDF 보고서 디자인
- PPTX 디자인
- 이미지 프롬프트/생성 품질
- 반려 사유 기반 재작업 품질
- 직원 간 인수인계 내용 품질

## 개발 운영 방식

앞으로 각 STEP은 다음 순서로 진행한다.

1. 기존 최신 소스 기준 확인
2. 해당 STEP 범위 고정
3. 기존 기능 영향 지점 확인
4. 구현
5. TypeScript/build 검증
6. 변경 파일만 ZIP 패치 제작
7. Vercel 배포 확인
8. 실제 화면/업무 1회 통합 테스트
9. 치명적 오류만 즉시 수정
10. 세부 AI 품질 문제는 STEP36 backlog에 기록하고 다음 기능으로 진행
