# STEP 18 — 업무 실행 큐

## 목표

STEP 17까지는 대표의 자연어 지시를 분석하고 실제 업무로 등록하는 단계였다.

STEP 18부터는 등록된 업무를 실제 회사 운영 상태로 이동시킨다.

기본 흐름:

1. 대기
2. 작업 중
3. 검수 대기
4. 대표 승인 대기 (필요한 경우)
5. 완료

예외 흐름:

- 보류
- 오류
- 다시 대기

## 안전 원칙

- 자동 완료 없음
- 대표 승인 필요 업무를 임의 완료하지 않음
- 결과물이 없는 상태에서도 상태 변경은 가능하되, 향후 STEP에서 결과물 검증을 추가
- 상태 변경은 대표 화면에서 직접 수행
- 삭제와 상태 변경은 별개

## 상태 코드

WAITING = 대기  
IN_PROGRESS = 작업 중  
REVIEW = 검수 대기  
PENDING_APPROVAL = 대표 승인 대기  
COMPLETED = 완료  
ON_HOLD = 보류  
ERROR = 오류

## 직원 작업량

직원별로 다음을 계산한다.

- 작업 중
- 대기
- 검수
- 승인 대기
- 오류

업무가 담당 직원 없이 등록된 경우 미배정으로 남는다.
