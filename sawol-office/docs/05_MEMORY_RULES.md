# SAWOL OFFICE — MEMORY RULES

## 기억 종류
1. 대표 기억
2. 프로젝트 기억
3. 결정 기억
4. 전문지식
5. 결과물 기억
6. 실패·문제 기억
7. 프롬프트 기억
8. 운영규칙 기억

## 대표 기억
디자인·문체·결과물 형식·기술·서비스·비용·품질 기준·싫어하는 방식·반복 수정사항·업무 방식 등을 저장한다. 중요도는 HIGH / MEDIUM / LOW.

## 프로젝트 기억
최초 지시, 목적, 참여 부서, Task, 기술, 서비스, 디자인, 결정, 수정, 문제·해결, 최종 결과, 향후 개선을 저장한다.

## 결정 기억
결정 내용뿐 아니라 결정 이유, 대안, 선택하지 않은 이유, 향후 영향, 재검토 조건까지 저장한다.

## 전문지식 신뢰도
VERIFIED / RELIABLE / INTERNAL / EXPERIMENTAL / UNVERIFIED

## 실패·문제 기억
버그, 잘못된 설계, 대표 반려, 불필요한 비용, 보안, 잘못된 리서치, AI 환각, 이미지 왜곡, 자동화 실패, 연동 오류를 기록하고 재발방지 규칙을 남긴다.

## 프롬프트 기억
이미지, 리서치, 개발, 코드검수, CS, 문서, 타로, 사주, 데이터, 자동화 프롬프트를 버전관리한다.

## 기억 저장 기준
반복 활용 가능, 강한 선호, 중요 결정, 프로젝트 영향, 오류 예방, 재사용 결과물, 전문지식 가치, 반복 질문 방지에 해당할 때 저장 검토한다.

## 기억하지 않아도 되는 것
단순 잡담, 일회성 질문, 단순 계산, 금방 의미 없어지는 정보, 업무와 무관한 사소한 대화, 중복 기억, 검증 안 된 임시 아이디어.

## 기억 충돌
적용 프로젝트, 날짜, 대표의 명시적 결정, 반복 횟수, 중요도, 상황 차이를 확인하고 해결 불가 시 대표에게 확인한다.

## 기억 우선순위
현재 대표 지시 > 현재 프로젝트 확정 결정 > 회사 사규 > 관련 대표 기억 > 과거 프로젝트 기억 > 일반 전문지식

## 상태
ACTIVE / SUPERSEDED / ARCHIVED / INVALID

## 프로젝트 종료 후
새 대표 선호, 중요한 결정, 재사용 결과물, 전문지식, 실패사례, 프롬프트, 새 규칙 필요 여부를 업데이트한다.
