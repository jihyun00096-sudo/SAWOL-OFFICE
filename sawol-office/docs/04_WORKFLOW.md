# SAWOL OFFICE — WORKFLOW

## 기본 업무 흐름
대표 지시 → 비서실 접수 → 업무 분석 → 업무 분류 → 담당 부서 선정 → 세부 Task 분해 → 작업 → 전문 검수 → 최종 검수 → 대표 승인 → 결과 저장 → 외부 활용 또는 다음 단계

## 업무 분류
리서치 / 기획 / 제작 / 수정 / 분석 / 운영 / 연구 / 프로젝트

## 프로젝트 기준
여러 부서가 참여하거나 여러 결과물, DB·개발, 장기관리, 비용·외부연동, 유지관리가 필요한 업무는 프로젝트로 분류한다.

## Task 상태
업무 대기 / 자료 대기 / 진행 중 / 협업 중 / 검수 중 / 대표 승인 대기 / 수정 요청 / 완료 / 보류 / 폐기 / 오류 발생

## 우선순위
긴급 / 높음 / 보통 / 낮음

## 검수 레벨
LEVEL 0 자체검수
LEVEL 1 전문검수
LEVEL 2 독립검수
LEVEL 3 고위험 검수

## 검수 판정
PASS / PASS WITH WARNING / REVISE / REJECT

## 대표 승인
승인 / 수정 요청 / 보류 / 폐기

## 자료 부족 시
프로젝트 기록 → 회사 기억 → 결정사항 → 첨부자료 → 다른 직원 결과 → 리서치 가능 여부를 먼저 확인한다.

## 비용 통제
기존 자료 → 현재 연결 AI → 무료 도구 → 저비용 모델 → 고성능 유료 모델 순으로 검토한다.

## 자동화 원칙
초기에는 반자동 인수인계로 운영하고 안정성 검증 후 일부 자동화한다. 대표 승인 단계는 자동화하지 않는다.

## 완료 기준
요청 충족, 필수 결과물 존재, 필요한 검수 완료, 중요 오류 없음, 대표 승인 완료, 인수인계 완료, 기록 저장 완료.
