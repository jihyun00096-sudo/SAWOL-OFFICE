# STEP 22 재정비 — AUTO / MANUAL 이중 운영

## 고정 원칙
- 기존 수동 기능은 삭제하지 않는다.
- 자동화는 기존 수동 엔진 위에 추가한다.
- 대표는 업무 등록 시 AUTO / MANUAL을 선택한다.
- AUTO 실행 중에도 언제든 MANUAL로 전환해 직접 개입할 수 있다.
- MANUAL에서 다시 AUTO로 넘길 때 기존 진행상태를 보존한다.
- 최종 승인/반려는 두 모드 모두 동일한 승인함을 사용한다.

## AUTO
업무 등록 → 비서 분석 → 단일/협업 판단 → 직원 자동 배정 → 자동 실행 → 내부 결과 연결 → 대표 승인 대기.

## MANUAL
업무 등록 → 기존 직원배정/실행세션/상태변경/업무수정 기능을 대표가 직접 사용.

브라우저를 닫아도 계속 도는 Background Worker, Discord/Notion/Google Calendar 연결은 STEP23 이후의 오케스트레이터/외부채널 계층으로 넘긴다. 이 기능들을 STEP22에 한꺼번에 섞지 않아 기존 안정 기능의 회귀 위험을 줄인다.
